# Contributing to BlackMint

Thank you for your interest in contributing to BlackMint.

## Current Status

BlackMint is currently in **private beta**. The codebase will be open-sourced following the public launch.

Watch this repository to be notified when it opens for public contributions.

## How to Contribute

### Reporting Bugs

Before submitting a bug report, please check existing issues to avoid duplicates.

When submitting a bug report, include:
- A clear and descriptive title
- Steps to reproduce the issue
- Expected behaviour vs actual behaviour
- Screenshots if applicable
- Your browser and operating system

### Suggesting Features

Feature suggestions are welcome. Please open an issue with:
- A clear description of the feature
- The problem it solves
- How you envision it working
- Any relevant examples from other products

### Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes following the code style guidelines below
4. Write clear, descriptive commit messages
5. Open a pull request against `main` and fill in the pull request template

## Code Style Guidelines

### General

- Write clean, readable, self-documenting code
- Keep functions small and focused on a single responsibility
- Add comments for complex logic, not obvious code

### TypeScript

- Use explicit types — avoid `any` where possible
- Use interfaces over type aliases for object shapes
- Follow existing naming conventions in the codebase
