# Contributing to BlackMint

Thank you for your interest in contributing to BlackMint.

## About This Repository

This repository is for support, documentation, and issue tracking. BlackMint's application source code (frontend and backend) is proprietary and is not hosted here, so this repository doesn't accept pull requests or code contributions. The best way to contribute is by reporting bugs and suggesting features below.

## Reporting Bugs

Before submitting a bug report, please check existing issues to avoid duplicates. When submitting a bug report, include a clear and descriptive title, steps to reproduce the issue, expected behaviour vs actual behaviour, screenshots if applicable, and your browser and operating system.

## Suggesting Features

Feature suggestions are welcome. Please open an issue with a clear description of the feature, the problem it solves, how you envision it working, and any relevant examples from other products.

## Code of Conduct

By contributing to BlackMint, you agree to maintain a respectful and professional environment. We have zero tolerance for harassment, discrimination, or abusive behaviour of any kind.

## Questions

For questions about contributing, open a GitHub Discussion or reach out via the contact details in the README.
